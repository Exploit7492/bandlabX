# AGENTS.md

Repo-specific notes for agent sessions. Read `HANDOVER.md` first; it is the source of truth for
sequencing and rules.

## Layout

- `src/resources/**` — one file (or directory) per API domain. Method JSDoc carries an
  `Evidence: apk` line naming the service the path came from.
- `api.md` — generated endpoint index. Do not hand-edit; regenerate with the `gen-*-api.py` scripts.
- `docs/research/apk-endpoints.md` — the evidenced path list (verb, auth, service, response shape).
- `docs/research/apk-shapes.tsv` — class → field → required, used to type responses.
- `docs/endpoint-status.md` — one row per endpoint with a hand-edited Status column.
- `docs/handover/**` — formula, ledger, per-leaf session notes, coverage matrix.

## Test conventions

- `tests/api-resources/<domain>/evidence.test.ts` — evidence tests. They stub `globalThis.fetch`,
  call the method, and assert the URL that actually reaches `fetch`, so a route regression fails
  here instead of in production. Generated by `scripts/research/gen-31-tests.py`.
- `tests/api-resources/<domain>/<domain>.test.ts` — Stainless Prism scaffolding. All skipped.
- Jest is 38 passing suites / 492 tests plus 46 skipped Prism suites.

## Regenerating things

- `scripts/research/gen-31-api.py` (leaves 15–40), `gen-32-api.py` (3.2), `gen-33-api.py` (3.3)
  rebuild `api.md` from the `*Params` interfaces and method signatures in `src/resources/**`.
- `scripts/research/sync-endpoint-status.py` merges the `./scripts/coverage --markdown` seed into
  `docs/endpoint-status.md`. It preserves every hand-set Status and takes `apk` / `apk-path-only`
  for new rows from `apk-endpoints.md`. Never regenerate that file wholesale.
- `scripts/research/evidence-coverage.py` pairs every path in `apk-endpoints.md` with a
  `this._client` call. `COVERED_BY_GENERIC` lists paths served by a shared method.

## Gotchas

- `scripts/research/gen-31-tests.py` scopes its `*Params` lookup to the owning class. Without that,
  nested messaging classes pick up the first `*Params` in the file and build paths with `undefined`.
- It also fills string-literal-union parameters with a real member (e.g. `'user'` for
  `'user' | 'band' | 'song'`), otherwise `tsc` rejects the generated test.
- `test_har_to_endpoints.py` pins the number of distinct verb+path keys in `endpoint-status.md`
  (rows collapse when one route serves two operations, e.g. `GET /revisions/{id}` plain vs
  `?format=m4a`). Bump it when a leaf adds rows. The loader regex must tolerate Prettier's column
  padding and a hyphenated status (`apk-path-only`); it once used `\w+` and single spaces, which
  silently dropped all 73 `apk-path-only` rows while the test still passed against the bad count.
- `./scripts/format` runs Prettier over the markdown tables in `docs/` and `README.md`. Anything that
  parses those tables must ignore padding, and `sync-endpoint-status.py --check` compares parsed
  rows rather than raw text for exactly this reason.
- The container image is built by `.github/workflows/container.yml`. Buildx rejects `push` and
  `load` together, so the job builds into the local daemon, smoke-tests it, then pushes the tags.
  GHCR rejects uppercase image paths, so the job lowercases `github.repository` (`Exploit7492`).
  See `docs/handover/CONTAINER.md`.
- `docs/handover/LEDGER.md` is append-only; never reorder lines.
- Pushing needs the owner token: the `Gh_token` secret authenticates as `Exploit7492` (admin,
  `push: true`). The default `GITHUB_TOKEN` authenticates as `Erudite885` and is **pull-only** on
  this repo, so a push with it fails `403 Permission ... denied to Erudite885`. Push as
  `git push https://x-access-token:${Gh_token}@github.com/Exploit7492/bandlabX.git HEAD:main`
  and leave the plain remote URL in place afterwards.
