# APK endpoint evidence

Generated by `scripts/research/apk-to-endpoints.py` from a jadx decompile of the BandLab Android app (11.33.2). Every row is a path the SDK does not expose today. `verb` comes from the annotation map, `auth` from `@ApiService.isAuthorized`, and `shape` from the kotlinx.serialization descriptor (real class and field names). Third-party SDK hosts (`AMPLITUDE_EXPERIMENT`, `AMPLITUDE_ANALYTICS`, `BRANCH`) are excluded by host, not by path, so BandLab paths under `/experiment/...` are kept.

Totals: **344 paths**, 344 with a verb, 265 with a response shape, 156 distinct response classes.
